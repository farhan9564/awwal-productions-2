# Awwal Productions — React + Node.js

The agency website now runs on Next.js App Router, React 19 and Node.js. Its existing design, supplied transparent logo, 26 pages, portfolio covers and campaign content are preserved as React components. Shared components handle the header, footer, mobile menu, animations and enquiry form.

## Development

Use Node.js 22 or newer.

```sh
npm ci
npm run dev
```

## Production and verification

```sh
npm test
npm run build
npm start
```

Vercel uses the checked-in `vercel.json` to install dependencies and build the Next.js application. Pushing to the connected production branch triggers deployment. Assets are served from `public/assets/` at the same `/assets/` URLs.

## Routes

- `/` — Home
- `/about`, `/services`, `/process`, `/contact`
- `/services/web-development`
- `/services/shopify-development`
- `/services/digital-marketing`
- `/services/social-media-management`
- `/portfolio` — Website portfolio
- `/portfolio/<project-name>` — Individual projects
- `/portfolio/meta-ads`, `/portfolio/mbm`, `/portfolio/digikon` — Meta Ads portfolio and case studies

All 26 old `.html` URLs permanently redirect to their new routes. Extensionless old project and service URLs also redirect. `lib/routes.mjs` lists the full mapping; `next.config.mjs` defines the redirects. Internal links and canonical metadata use the new routes. `/sitemap.xml` and `/robots.txt` are generated by Next.js.

## Enquiries

`POST /api/enquiry` runs on Node.js, validates the form and prepares encoded email/WhatsApp links. It does not store enquiries or send messages. Visitors review and send the prepared message in their own email app or WhatsApp, preserving the original contact workflow. No mail service or secrets are required.

## Editing

- `app/**/page.jsx`: page content, React markup and per-page metadata.
- `components/`: shared navigation, footer, client interactions and contact form.
- `app/globals.css`: existing visual system and responsive styles.
- `public/assets/awwal-logo.svg`: display wrapper containing the exact supplied transparent image; its viewBox removes empty margins without altering the image.
- `lib/enquiry.mjs`: enquiry validation and message preparation.

The canonical production domain remains `https://awwalproductions.com`. Change it in the root metadata, structured page data, sitemap and robots configuration if the production domain changes.

Portfolio cover images remain the existing showcase graphics. They should not be represented as independently verified homepage screenshots. Campaign figures retain the original source context.
